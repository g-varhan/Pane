## 2025-06-14 - Path Traversal (Zip Slip) in Tar Extraction
**Vulnerability:** When extracting tar archives during container image conversion (`pane-api/panespec/container.go`), the code used `filepath.Join(tempRootfsDir, filepath.Clean(header.Name))` to determine the destination path. This does not protect against "Zip Slip" or path traversal attacks because `filepath.Clean` doesn't remove `../` elements that resolve above the current directory when joined with another path in some cases, or more accurately, when extracting `../../../../etc/passwd`, it might write outside the temp directory. Wait, actually `filepath.Join(base, target)` is vulnerable to `../../` in `target`. Wait, let's verify. My test program showed `filepath.Join("/tmp/root", "../etc/passwd")` resulted in `/tmp/etc/passwd`, which is outside `/tmp/root`!
**Learning:** `filepath.Join(base, target)` does not prevent path traversal if `target` starts with `../`. It just does a string concatenation followed by `filepath.Clean`. When processing archives from untrusted sources (like public container registries), this allows an attacker to overwrite arbitrary files on the host (e.g., `/etc/passwd`).
**Prevention:** Always implement a `secureJoin` function or manually verify that the resulting absolute path starts with the expected base directory prefix after joining.
