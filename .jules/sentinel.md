## 2025-02-14 - Fix Path Traversal in tar extraction
**Vulnerability:** Path traversal (Zip Slip) vulnerability during container image tar extraction (`PullContainerImage`). Unsanitized header names allowed writing to arbitrary paths outside the temporary rootfs via `filepath.Join(tempRootfsDir, filepath.Clean(header.Name))`.
**Learning:** `filepath.Clean` is insufficient when used alone with `filepath.Join` if the unsanitized input contains enough `../` sequences to escape the base directory. Evaluating the untrusted path as an absolute path first via `filepath.Clean("/" + untrusted)` forces evaluation relative to an imaginary root, effectively removing traversing sequences without escaping.
**Prevention:** Always use a custom `secureJoin` function when extracting archives. The formula `filepath.Join(base, filepath.Clean("/" + untrusted))` mitigates path traversal by evaluating the path independently and correctly resolving `../` elements before being appended to the `base` directory path.
