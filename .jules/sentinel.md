## 2024-06-15 - Path Traversal during container extraction
**Vulnerability:** In `PullContainerImage`, the tar extraction loop combined the target directory with the tar header's file name using `filepath.Join(tempRootfsDir, filepath.Clean(header.Name))`. However, `filepath.Clean` doesn't remove `../` elements that exceed the "root" of the relative path. This allowed malicious tarballs to include files named `../../../../etc/passwd` that would break out of `tempRootfsDir` and overwrite host files.
**Learning:** `filepath.Clean` and `filepath.Join` are not safe enough by themselves to prevent path traversals when unpacking archives if the archive paths can contain arbitrary numbers of `../` prefixes. `filepath.Clean("foo/../../bar")` becomes `"../bar"`.
**Prevention:** Always write a `secureJoin` function when extracting archives. A robust pattern in Go is to root the untrusted path by prepending `/` before cleaning (`filepath.Clean("/" + untrusted)`), which resolves all `../` within an absolute context, and then strip the leading `/` before joining with the base directory. Finally, verify `strings.HasPrefix(joinedPath, baseDir + string(filepath.Separator))` as a paranoia check.
