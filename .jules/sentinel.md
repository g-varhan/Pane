## 2026-06-17 - Path Traversal during Archive Extraction
**Vulnerability:** A Zip Slip/Tar Slip path traversal vulnerability was identified in `pane-api/panespec/container.go` where untrusted archive entry names were extracted relative to a target directory using `filepath.Join(tempRootfsDir, filepath.Clean(header.Name))`. An attacker could include `../` sequences in the archive header to extract files outside the intended rootfs directory (e.g., overwriting `/etc/passwd` or other sensitive host files).
**Learning:** `filepath.Clean(untrusted)` alone does not prevent path traversal if the untrusted path contains sufficient `../` sequences to break out of the base directory. The untrusted input must be treated as an absolute path before cleaning.
**Prevention:** Always use a `secureJoin` pattern when extracting archives: `filepath.Join(base, filepath.Clean("/" + untrusted))`. The leading slash forces `filepath.Clean` to resolve `../` components relative to root, effectively confining the result within the base directory when joined.
