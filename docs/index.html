🏗Architecture

text
+======================================================+
|              pane-cli   +   pane-api                 |  Go
|    cobra CLI  |  gRPC server  |  CGo FFI to core     |
+======================================================+
|               pane-core  (orchestration)             |  Rust
|   VM state machine  |  cgroup v2  |  eBPF  |  snaps  |
+======================================================+
|                pane-vmm  (VMM layer)                 |  C
|   /dev/kvm ioctls  |  vCPU run loop  |  io_uring     |
+======================================================+
LayerLanguageWhat it does
pane-vmmCKVM ioctls, vCPU run loop, io_uring disk I/O, Firecracker & QEMU backends
pane-coreRustVM state machine (typestate), cgroup v2 limits, eBPF network segmentation, snapshot/fork
pane-api/cliGogRPC daemon, CGo FFI into Rust, CLI (cobra)

⚙Installation

One-liner

bash
curl -fsSL https://raw.githubusercontent.com/pane-vmm/pane/main/install.sh | bash

Options

bash
# Custom install prefix
curl -fsSL .../install.sh | bash -s -- --prefix=/opt/pane

# Skip dependency install
curl -fsSL .../install.sh | bash -s -- --skip-deps

# Don't install the systemd daemon
curl -fsSL .../install.sh | bash -s -- --no-daemon

# Local clone
git clone https://github.com/pane-vmm/pane.git && bash Pane/install.sh

🗑Uninstallation

bash
# Preserve images and snapshots (safe default)
curl -fsSL https://raw.githubusercontent.com/pane-vmm/pane/main/uninstall.sh | bash

# Remove EVERYTHING including images and snapshots
bash uninstall.sh --purge

# Custom prefix
bash uninstall.sh --purge --prefix=/opt/pane
⚠--purge permanently deletes all images in /var/lib/pane. Without it, images and snapshots are kept.

🔌Daemon Management

Pane runs as a gRPC daemon on /run/pane.sock. The CLI auto-starts it if not running.

bash
pane daemon start                   # Start daemon
pane daemon start --socket /tmp/my.sock
pane daemon stop                    # Stop daemon
pane daemon status                  # Check status

systemd service

bash
sudo systemctl start   pane     # Start
sudo systemctl stop    pane     # Stop
sudo systemctl restart pane     # Restart
sudo systemctl enable  pane     # Auto-start on boot
sudo systemctl status  pane     # Status
journalctl -u pane -f           # Follow logs

▶pane run

Boot a VM from a pulled image or explicit parameters.

bash
# Simplest usage
pane run alpine

# Override resources
pane run ubuntu --cpus 4 --memory 4GiB

# Assign a name
pane run alpine --name my-sandbox

# Desktop with VNC
pane run ubuntu-desktop --gui

# Firecracker MicroVM mode
pane run --kernel /boot/vmlinuz --cmdline "console=ttyS0 root=/dev/vda"

# PaneSpec config file
pane run -f /path/to/myvm.json

# Dry run
pane run --dry-run ubuntu

Flags

--cpusuintfrom imageNumber of virtual CPUs
--memorystringfrom imageRAM: 256MiB, 2GiB
--disk-sizestring—Create blank writable disk

--kernelstring—Linux kernel (Firecracker mode)
--cmdlinestring—Kernel command-line args
--guiboolfalseEnable VNC on port 5901

💻pane exec

Run a command inside a running VM via vsock. Latency: < 10 ms p99.

bash
pane exec my-sandbox uname -a
pane exec my-sandbox sh -c "apt update && apt install -y curl"
pane exec my-sandbox cat /etc/os-release

# Pipe stdin
echo "hello" | pane exec my-sandbox cat -

⏹stop · rm · logs · inspect

bash
# Gracefully stop
pane stop my-sandbox

# Destroy (kill + reclaim resources)
pane rm my-sandbox

# View serial output
pane logs my-sandbox
pane logs -f my-sandbox   # Follow

# Full runtime state JSON
pane inspect my-sandbox

📸pane snapshot

Freeze running VM RAM + vCPU state to disk in < 100 ms (4 GB VM).

bash
pane snapshot my-sandbox

# Resume from snapshot
pane run --snapshot /var/lib/pane/snapshots/my-sandbox alpine

🔀pane fork

Clone a snapshot into new VMs using Linux reflinks (CoW). 50 clones in < 2 seconds.

bash
pane fork my-sandbox clone-1
pane fork my-sandbox clone-1 clone-2 clone-3

# 50 parallel clones
for i in $(seq 1 50); do
  pane fork my-sandbox worker-$i &
done
wait

📡gRPC SDK (Go)

Embed Pane directly in your Go service.

go
conn, _ := grpc.Dial("unix:///run/pane.sock",
    grpc.WithTransportCredentials(insecure.NewCredentials()))
client := pb.NewPaneServiceClient(conn)

ctx := context.Background()

// Spawn a VM
resp, _ := client.Spawn(ctx, &pb.SpawnRequest{
    Id:       "my-vm",
    SpecJson: `{"vmm":"qemu","cpus":2,"memory":"2GiB"}`,
})
log.Printf("PID=%d, VsockCID=%d", resp.Pid, resp.VsockCid)

// Exec a command
out, _ := client.Exec(ctx, &pb.ExecRequest{
    Id:  "my-vm",
    Cmd: []string{"uname", "-a"},
})

// Snapshot + fork 10 clones
client.Snapshot(ctx, &pb.SnapshotRequest{Id: "my-vm"})
for i := 0; i < 10; i++ {
    client.Fork(ctx, &pb.ForkRequest{
        SourceId: "my-vm",
        NewId:    fmt.Sprintf("worker-%d", i),
    })
}

🚀Advanced Use Cases

Serverless Sandbox (E2B / Modal pattern)

bash
# 1. Boot golden VM, install deps
pane run alpine --name golden
pane exec golden sh -c "apk add python3 && pip install numpy"

# 2. Snapshot warm state
pane snapshot golden

# 3. Fork 50 workers (< 2s total)
for i in $(seq 1 50); do pane fork golden worker-$i &; done; wait

# 4. Distribute work
for i in $(seq 1 50); do pane exec worker-$i python3 /tasks/task-$i.py &; done; wait

# 5. Destroy all
for i in $(seq 1 50); do pane rm worker-$i; done

CI Runners

bash
JOB_ID="ci-${GITHUB_RUN_ID}-${GITHUB_JOB}"
pane run ubuntu --name "$JOB_ID" --cpus 4 --memory 8GiB
pane exec "$JOB_ID" bash /repo/.github/scripts/build.sh
EXIT_CODE=$?
pane rm "$JOB_ID"
exit $EXIT_CODE

Security Research

bash
# Clean baseline
pane run debian --name clean-debian
pane snapshot clean-debian

# Analyze sample in a disposable clone
pane fork clean-debian analysis-run-1
pane exec analysis-run-1 bash -c "cd /malware && ./run.sh"
pane rm analysis-run-1

🛠Troubleshooting

/dev/kvm: Permission denied

bash
sudo usermod -aG kvm $USER
newgrp kvm   # or log out and back in

Daemon won't start

bash
pgrep -x pane
sudo rm -f /run/pane.sock /tmp/pane.sock
pane daemon start

libpane_core.a not found

bash
cd pane-core && cargo build --release
sudo cp target/release/libpane_core.a /usr/local/lib/
sudo ldconfig

VNC not connecting

bash
ss -tlnp | grep 590        # Verify port 5901
pane inspect tiny10        # Check extra_args
vncviewer localhost:5901

Download fails with HTTP 403

bash
# Download manually and register locally
wget -O /tmp/myimage.iso https://example.com/image.iso
TINY10_ISO_PATH=/tmp/myimage.iso pane pull tiny10
