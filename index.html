Technology & Performance Stack

Pane utilizes modern Linux kernel primitives for maximum throughput and isolation.

Asynchronous I/O via io_uring

The `virtio-blk` device MMIO path integrates with a dedicated `io_uring` ring to execute storage operations asynchronously, achieving over 3,100 MB/s read speeds (a 199% boost over sync pread).

eBPF TC Ingress Classifier

Implements zero-rules micro-segmentation. Using the Rust `aya` loader, a BPF map matches source/destination VM IPs and blocks unauthorized group crossings directly in the kernel network path with zero host overhead.

cgroup v2 Resource Caps

Automatically manages CPU weight scheduler configurations, OOM memory ceilings, and process limit counts per VM, trapping guest out-of-memory states inside local groups without impacting host services.

Stateless CGo gRPC Server

Links the core Rust static archive `libpane_core.a` with Go. Allows scalable goroutines to manage gRPC execution requests asynchronously while keeping VM records stateless on the API host.
